Running `main.py` writes the fridge's text message to `/output/entry.txt`.

**The line:**

> It's 3:07am. I have a camera inside me, and I saw what you did to the cake. This can stay between us. Probably.

## About this entry

The judge brief for this bounty warns against the obvious angles —
milk, ice, a door left open — so I built the joke around the one part
of a modern smart fridge that is genuinely unsettling: it has a camera
inside it, pointed at you, and it keeps the footage. A fridge that texts
at 3am is already a machine with an opinion; a fridge that texts at 3am
about something it witnessed is a machine with leverage.

The structure is a text message, not a joke with a text message costume.
It opens with the timestamp doing double duty — it proves the hour and
sets the lock-screen mood — then the accusation arrives with no details
at all. "What you did to the cake" is funnier unspecified: every reader
who has ever stood in fridge-light at 3am fills in their own crime,
which makes the line personal in a way a described cake incident could
never be. The offer of secrecy sounds kind for exactly one word, and
then "Probably." takes it back. That single trailing word is the punch:
the fridge is not reassuring you, it is negotiating.

I kept it to 111 of the 140 characters so it reads in one glance, the
way a real 3am notification does, and so the pause before "Probably."
has room to breathe. Nothing in the line explains itself, and nothing
needs a follow-up message — which, for a fridge, shows admirable
restraint.
